# 💍 Will you marry me? — 프로포즈 게임

`index.html` 하나로 동작하는 프로포즈용 웹 게임입니다.

## 실행

### Windows 실행 파일 (권장)

`dist/proposal.exe`를 더블클릭하면 Edge(없으면 Chrome)가 주소창 없는 **전체화면 앱 창**으로 열립니다.
- 설치가 필요 없는 단일 파일입니다(게임이 실행 파일 안에 내장됨).
- 종료: `Alt + F4` (창을 닫으면 실행기도 자동 종료)
- `proposal.exe`와 같은 폴더에 `music.mp3`를 두면 그 음악이 재생됩니다.
- 처음 실행 시 Windows SmartScreen 경고가 뜨면 `추가 정보 → 실행`을 누르세요(서명되지 않은 파일이라 뜨는 일반 경고).

다시 빌드하려면(Go 1.24+): `./build.sh` → `dist/proposal.exe`

### 브라우저로 직접 실행

```bash
cd proposal
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 → 전체화면(F11) 권장
```

`index.html`을 더블클릭해서 열어도 됩니다. 폰트는 Google Fonts에서 불러오므로 인터넷 연결이 필요합니다.

## 흐름

1. **인트로** – 화면을 누르면 음악이 시작됩니다(브라우저 자동재생 정책 때문에 첫 터치가 필요).
2. **질문** – "Will you marry me?" / YES · NO
   - NO 버튼은 처음엔 YES 바로 옆에 있다가, 커서와의 거리를 매 프레임 계산해 반경(150px) 안으로 들어오면 커서 반대 방향으로 **가속**해서 도망갑니다.
   - 커서가 빠르게 다가올수록 가속도가 커지고, YES 버튼에 막히면 그 면을 타고 돌아 나가며, 화면 벽에서는 반발계수 0.55로 부드럽게 튕기거나 테두리를 따라 미끄러지며 모서리에선 옆으로 빠져나갑니다.
   - 어쩌다 NO가 눌리면(터치 등) 순간 튕겨 나가고, YES 버튼이 점점 커집니다.
3. **결과** – 청혼서(진은영 「청혼」 일부를 빌려 고쳐 쓴 글귀) + "김연준 & 신우정", 승낙 도장, 꽃잎, 우측 하단 `made by 연준`.

물리 파라미터는 `index.html`의 `PHYS` 객체에서 조절할 수 있습니다.

## 음악

기본으로 파헬벨 「캐논 D장조」(퍼블릭 도메인)를 Web Audio API로 직접 연주합니다(피아노 아르페지오 → 바이올린 선율 → 화음 순으로 쌓임, 리버브 포함).
원하는 음원이 있으면 `proposal/music.mp3`로 넣어두면 그 파일이 우선 재생됩니다. 우측 상단 ♪ 버튼으로 음소거할 수 있습니다.
