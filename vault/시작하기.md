# 시작하기 — 옵시디언 연결 방법

이 폴더(`vault/`)의 노트는 GitHub 저장소 `highyj93-lab/test_1`의 `claude/dart-api-connection-3wu9vj` 브랜치에 있습니다. Claude가 새 분석을 push하면 옵시디언에서 pull로 받아오는 구조입니다.

## 1. 저장소 받기
```bash
git clone -b claude/dart-api-connection-3wu9vj https://github.com/highyj93-lab/test_1.git
```
브랜치를 main에 병합한 뒤에는 `-b` 옵션 없이 받으면 됩니다.

## 2. 옵시디언에서 열기
- 옵시디언 → **Open folder as vault** → 받은 `test_1` 폴더를 선택합니다.
- 저장소 최상위 폴더를 볼트로 열어야 Obsidian Git이 동작합니다. 코드 파일도 있지만 옵시디언에서는 마크다운과 이미지만 보입니다.
- 시작 노트: [[국민연금 지분확대 분석 2026-10]]

## 3. 플러그인 설치
설정 → 커뮤니티 플러그인 → 제한 모드 끄기 → 찾아보기에서 설치합니다.
- **Obsidian Git**: 동기화용. 설정에서 'Auto pull interval'을 예: 10분으로 지정하고, 'Pull on startup'을 켭니다.
- **Dataview**: 허브·섹터 노트의 점수표를 노트 속성에서 자동으로 만듭니다.

## 4. 주의
- 개인 메모를 이 볼트에 쓰고 push하면 GitHub에 올라갑니다. 저장소를 비공개로 두는 것을 권합니다.
- Claude가 같은 노트를 다시 생성할 수 있으니, 직접 메모는 노트 맨 아래에 따로 적거나 별도 노트에 쓰는 게 충돌을 줄입니다.
- `.obsidian/workspace*.json` 같은 개인 화면 설정은 커밋되지 않도록 `.gitignore`에 넣어두었습니다.
