# 방법론과 데이터

[[국민연금 지분확대 분석 2026-10|분석 허브]]로 돌아가기

## 데이터 출처
- **DART Open API**: `list.json`(공시검색), `majorstock.json`(대량보유 상황), `elestock.json`(임원·주요주주 소유), `document.xml`(공시 원문)
- **네이버 증권 모바일 API**: 일별 시세, PER·추정PER·PBR·컨센서스 EPS·목표주가
- **웹 리서치**: 증권사 리포트·뉴스를 섹터별 리서치 에이전트 4개가 종합
- KRX 데이터 포털(pykrx)은 로그인이 필요해 쓰지 못함

## 종목 선정
1. 2026.07.05~10.03 지분공시(D유형) 8,974건 중 제출인이 국민연금공단인 177건을 고름
2. 보고서 유형별로 보유비율 확인

| 보고서 유형 | 건수 | 확인 API |
|---|---|---|
| 주식등의대량보유상황보고서(약식) | 130 | majorstock.json |
| 임원·주요주주특정증권등소유상황보고서 | 47 | elestock.json |

3. 보유비율 10% 이상이고 직전 보고 대비 증가한 건만 남김 → 22개 종목

> [!note] 정정 이력
> 처음에는 대량보유 130건만 봐서 10개 종목을 찾았음. [[이수페타시스]] 누락 지적으로 임원·주요주주 47건을 추가 분석해 12개 종목을 더함.
> 임원·주요주주 보고에서 증감이 보유량 전체와 같은 건은 실제 매수량이 아니라 10%를 처음 넘겨 보고 대상이 된 시점이라는 뜻.

## 점수 (각 1~5점, 총 15점)
- **실적추정치**: 리서치 정성 점수와 컨센서스 EPS 성장률 점수의 평균
  - EPS 성장률: 50% 초과 5점 / 20% 초과 4점 / 5% 초과 3점 / -5% 초과 2점 / 그 이하 1점
- **업황 전환**: 리서치 정성 점수
- **밸류에이션**: 추정PER 점수와 PBR 점수의 평균 (10/1 종가 기준)
  - 추정PER: 8배 미만 5점 / 12배 미만 4점 / 18배 미만 3점 / 30배 미만 2점 / 그 이상 1점
  - PBR: 0.5배 미만 5점 / 0.8배 미만 4점 / 1.5배 미만 3점 / 5배 미만 2점 / 그 이상 1점

## 한계
- 업황과 일부 실적 점수는 정성 평가. [[DL]]·[[한화엔진]] 등은 데이터 부족으로 판단에 의존.
- 네이버 수치는 KRX 공식 수치와 기준이 조금 다를 수 있음.
- [[씨에스윈드]]는 직전 EPS가 매우 작아 EPS 성장률이 비정상(+4,179%), 점수 상한 적용.
- 목표주가 상승여력은 오래된 목표가가 섞여 있을 수 있어 점수에서 제외.
- 9/24~26 추석 연휴는 시세 데이터 없음.
- 투자자문 아님.
